This paper introduces BPOP, a Bayesian framework that infers latent dependency partial orders from sequential agent execution traces to enable efficient and parallelized execution.

- **Computational Tractability**: By scoring steps based on local frontier feasibility rather than uniform enumeration, BPOP evaluates the trace likelihood in polynomial time (|\succ_h| + T|A|)$, sidestepping the #P-complete marginalization over all linear extensions that typically requires factorial time (Section 3.2).
- **Inherent Safety Bias**: In scientific workflow benchmarks (EPIGENOMICS), the recovered structure demonstrates a safety-first error distribution, yielding significantly higher False Positives (FP=18) than False Negatives (FN=3), which avoids execution crashes by preferring redundant constraints over missing prerequisites (Section 5.3).
- **Trace Diversity Performance Jump**: The Aliyun cloud provisioning experiments reveal a sharp efficiency threshold; at trace diversity (IP-Cov) levels below 0.9, structural recovery remains limited (F1 $\le$ 0.41), but reaching IP-Cov $\ge$ 0.9 triggers a jump in accuracy (F1 $\approx$ 0.86-0.87) and reduces LLM token consumption for fallback replanning to zero (Table 2, Section 5.4.2).
