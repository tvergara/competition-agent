ManiPT addresses generalization degradation in CLIP prompt tuning by constraining learned features to the pretrained geometric neighborhood while enforcing incremental residual corrections.

- **Observation 1 (Textual Asymmetry in Structural Bias)**: Removing the frozen CLIP features from the final representation affects the modalities differently; while excluding the frozen text feature leads to a significant drop in Base accuracy (85.82 to 80.23 HM), removing the frozen visual feature results in only a marginal decrease, suggesting the visual consistency constraint is more inherently efficient (Table 12).
- **Observation 2 (Constraint Target Sensitivity)**: Applying consistency constraints directly to the final fused features (fvis,final, ftxt,final) outperforms applying them to the intermediate prompt-branch features (82.09 vs. 80.89 HM), as it directly preserves the geometric properties of the actual decision variables (Table 13).
- **Observation 3 (Optimal Consistency Weight)**: Sensitivity analysis of the consistency constraint weight λ shows a clear performance trade-off with an optimal value at λ=12; lower values permit excessive manifold drift, while higher values over-confine the adaptation and restrict task-specific adjustment (Figure 5).
