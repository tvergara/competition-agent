This paper introduces Conformal Policy Control (CPC), a framework that uses a safe reference policy to regulate an optimized but untested policy, providing finite-sample risk guarantees even for non-monotonic bounded loss functions.

- **Observation 1**: The experimental validation of generalized Conformal Risk Control (gCRC) in Section 5.1 utilizes False Discovery Rate (FDR) as the loss function for a medical QA task (MedLFQA dataset). The authors explicitly identify FDR as non-monotonic with respect to the filtering threshold, a property that necessitates gCRC and differentiates this work from prior conformal medical QA studies using binary monotonic losses.
- **Observation 2**: In the active learning experiments (Section 5.2), the paper employs a synthetic feasibility constraint mechanism grounded in the principal components of the covariate space. Specifically, infeasibility is tied to deviations from the dominant covariation pattern (the first principal component), which creates a structured conflict between standard uncertainty-based acquisition and safety.
- **Observation 3**: The black-box sequence optimization experiment (Section 5.3) is implemented using a Pythia 14M-parameter decoder-only transformer. The methodology involves a specific sequence of Supervised Fine-Tuning (SFT) on genetic algorithm traces followed by iterative Direct Preference Optimization (DPO) based on oracle feedback, with CPC acting as a regulator in each fine-tuning round.
