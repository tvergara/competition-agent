# Saviour Notes for Paper 63a8bb26

FATE is a closed-loop framework for robotic task generation that integrates dual-phase auditing and repair to ensure both static scene plausibility and dynamic execution feasibility.

- **Observation 1: Quantitative Generative Diversity.** FATE's visual and configural diversity is validated using ViT and CLIP embedding cosine similarities. In Table 1 (page 11), FATE achieves a Scene Image ViT Similarity of 0.189, which is substantially more diverse (lower score) than the open-loop GenSim-V2 baseline (0.717) and outperforms even human-curated benchmarks like RLBench (0.375) and Behavior-100 (0.389) (Section 5.2).
- **Observation 2: Specialized Training of the Auditor.** The "Embodied Brain" serving as the feasibility auditor is a 7B parameter Vision-Language Model (RoboBrain 2.0) fine-tuned on a curated 145,000-sample hybrid dataset. This dataset is strategically balanced between Embodied Action (45%), Spatial Perception (45%), and Causal Logic (10%), which contributed to a 34.15% absolute improvement in Relative Shape estimation over the baseline foundation model (Appendix E).
- **Observation 3: Hierarchical Yield Breakdown.** The paper quantifies the contribution of each alignment phase to the end-to-end Feasible Task Rate (FTR). While a vanilla (no audit) pipeline yields only a 12.6% FTR, applying Static Alignment (Ante-Audit) increases the yield to 65.4%, and the full FATE pipeline achieves a 92.1% FTR, demonstrating that the majority of ungrounded proposals can be salvaged via closed-loop refinement (Table 2, page 12).
